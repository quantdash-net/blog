"有没有免费的股票数据接口？"几乎是每个刚开始做量化的人都会问的问题。答案是有，而且不少。但免费或低成本的数据来源，代价往往藏在别的地方：字段口径不清楚、接口说变就变、能不能商用没人说得清、数据错了也没处反馈。

这篇文章按常见问题的形式，整理免费和低成本数据来源的**主要类型**、各自适合的场景，以及评估时最容易踩的坑。文章不点评任何具体产品；涉及 QuantDash 的部分只引用 [官方文档](https://docs.quantdash.net/zh-Hans) 和 [官网](https://quantdash.net/) 的原文。

## 免费 / 低成本数据来源有哪几类？

按数据从哪来、以什么方式提供，大致可以分成五类：

| 类型 | 典型形式 | 优点 | 需要注意 |
| --- | --- | --- | --- |
| 交易所和监管机构公开信息 | 官网公告、统计数据、可下载的文件 | 权威、口径清楚 | 多为公告和统计类信息，不一定提供可编程的行情接口 |
| 开源数据工具包 | 社区维护的 Python 包，整理多个公开网页的数据 | 安装即用、覆盖面广 | 依赖上游网页结构，上游改版就可能失效；授权需自行确认 |
| 交易软件或券商附带的接口 | 客户端插件、终端内置的数据函数 | 与交易环境结合紧密 | 通常绑定账户和客户端，迁移到服务器环境不一定方便 |
| 商业数据 API 的免费额度 | 注册后可用的免费方案或试用 | 有文档、有错误码、有服务方 | 免费额度通常只覆盖部分市场或数据类型，频率有限制 |
| 自己抓取网页 | 写爬虫解析行情页面 | 不花钱 | 稳定性差、维护成本高，还可能违反网站条款 |

没有一类是"最好的"，关键是和你的用途匹配。下面按问题逐个展开。

## 只是学习和练手，用什么就够了？

如果目标是学 pandas、练习指标计算、跑一个简单的均线回测，**日线级别的数据就足够了**，对时效基本没有要求。这时开源工具包或商业 API 的免费额度都可以。

建议选的时候看两点：

- **能不能稳定复现**：同样的代码今天能跑、下个月还能跑。如果数据来源经常改版，学习过程会被大量的修修补补打断。
- **字段是否说明清楚**：至少要知道价格是否复权、成交量的单位是什么。

## 要做长期研究或回测，免费数据够用吗？

可以用，但要多做一步**数据校验**。长期研究对数据质量的要求比练手高得多，常见问题包括：

- **复权口径**：前复权、后复权还是不复权？比例复权还是差值复权？不同口径算出的收益率和价格差异可能很大。
- **停牌和缺失**：停牌日是缺行还是填充？缺失的交易日会让滚动指标错位。
- **历史深度**：能取多少年？更早的数据是否完整？
- **幸存者偏差**：标的列表是否包含已退市的股票？

一个简单可行的做法是：抽几只经历过分红送转的股票，用两个不同来源对比除权日前后的价格，确认口径一致后再大规模使用。

## "实时行情"免费吗？要注意什么？

不少来源都提供"实时"或"准实时"行情，但这个词的含义差别很大。评估时要分清三个概念：

1. **快照刷新频率**：服务端多久更新一次价格。
2. **接口响应时间**：一次请求多久返回。
3. **调用频率限制**：单位时间允许请求多少次。

这三者互相独立，不能用其中一个数字代替另一个。比如 QuantDash 文档 FAQ 写的是"实时行情快照约 3 秒刷新一次"，这是刷新频率口径；如果你的程序每秒轮询多次，拿到的大多是同一份快照，还会更快触发频率限制。

另外，不同市场的实时数据在授权上通常有不同的规定，免费来源上看到的港股、美股行情是否实时、是否允许用于产品展示，需要以对应服务的说明为准。

## 免费数据能用在商业产品里吗？

这是最需要谨慎的问题，本文不能替你下结论，只能给出检查方法：

- **读服务条款原文**，重点看使用范围（个人研究 / 内部使用 / 对外展示）、再分发和转售限制、存储和缓存的限制。
- **开源工具包的许可证只覆盖代码本身**，不代表它抓取的数据可以随意使用。数据的授权要看数据原本来自哪里。
- **有疑问就书面询问服务方**，并保留回复。

如果产品要对外展示行情，最稳妥的方式是使用条款中明确允许该用途的数据服务。

## 评估免费 / 低成本接口的 10 个注意事项

把上面的问题汇总成一张可以逐条打勾的清单：

1. **授权**：用途是否在条款允许范围内，能否展示、能否再分发。
2. **稳定性**：接口是否有版本管理，上游改版时会不会突然失效。
3. **文档**：参数、字段、单位、错误码是否有文档说明。
4. **复权口径**：支持哪些复权方式，默认值是什么。
5. **市场与周期覆盖**：需要的市场、日线、分钟线是否都在免费范围内。
6. **历史深度**：能回溯多久，是否包含退市标的。
7. **频率口径**：快照刷新频率、接口响应时间、调用频率限制分别是多少，不要混用。
8. **错误处理**：Key 无效、无权限、超频时返回什么，能否区分。
9. **升级路径**：免费额度不够时，升级是按市场、按功能还是按调用量计费。
10. **迁移成本**：数据格式和代码格式是否通用，换数据源要改多少代码。

## QuantDash 的免费额度包含什么？

以下内容均来自 QuantDash 官网定价页和文档的原文：

- **免费额度**：注册即获免费额度，包含 A 股实时行情和日 K 线，可直接调用 API 验证数据质量。
- **市场**：覆盖 A 股（沪深京）、美股、港股，不同市场独立订阅、按需组合。
- **数据类型**（文档 FAQ）：实时行情快照、日/周/月 K 线、分钟 K 线（1m/5m/15m/30m/60m）、日内分时、五档盘口、除权因子、标的元数据。不同数据类型和市场需要对应方案的权限。
- **刷新频率**（文档 FAQ）：实时行情快照约 3 秒刷新一次，K 线数据盘中实时更新。
- **升级与退款**：直接购买新方案，系统自动合并所有活跃订阅的权限；所有付费方案享 7 天无理由退款（扣除支付手续费）。

各方案的具体价格和调用额度以 [定价页](https://quantdash.net/pricing) 实时显示为准，本文不引用具体数字。

用免费额度验证数据时，可以从一个最小脚本开始（Key 放在环境变量里，不要写进代码）：

```python
import os
from quantdash import QuantDash

qd = QuantDash(api_key=os.environ["QUANTDASH_API_KEY"])

# A 股日 K：显式指定复权方式
df = qd.klines.get("600519.SH", period="1d", count=20, adjust="forward", to_dataframe=True)
print(df[["trade_date", "open", "close", "volume"]].tail())

# A 股实时快照：按代码查询
quotes = qd.quotes.get(symbols=["600519.SH", "000001.SZ"], to_dataframe=True)
print(quotes[["symbol", "last_price", "prev_close", "ext.change_pct"]])
```

如果某个请求返回 403，文档的说明是"无权限（套餐不包含该功能或市场）"，说明这项数据不在当前额度内，而不是 Key 有问题（Key 无效对应的是 401）。

## 怎样用最低成本搭一套够用的数据方案？

几条实用建议：

- **先用日线把研究流程跑通**，确认策略方向有价值，再考虑分钟线和实时数据的投入。
- **只订阅真正要用的市场**。如果数据服务按市场计费，先从主要研究的市场开始。
- **能批量就不要逐只请求**，能按标的池取快照就不要循环查询，这样同样的额度能做更多事。
- **历史数据落盘缓存**，复权价格要记录复权口径；新的除权发生后前复权价格会变化，需要定期刷新。
- **加一层自己的数据访问函数**，以后换数据源或混用多个来源时，策略代码不用改。

## 问答小结

**问：免费股票数据接口主要有哪几类？**
答：交易所和监管机构的公开信息、开源数据工具包、交易软件或券商附带的接口、商业数据 API 的免费额度，以及自己抓取网页。它们在稳定性、文档完整度和授权清晰度上差别很大。

**问：免费数据适合做回测吗？**
答：可以，但要先核对复权口径、停牌处理、历史深度和是否包含退市标的，抽样对比除权日前后的价格后再大规模使用。

**问："实时行情"要看哪个指标？**
答：分别看快照刷新频率、接口响应时间和调用频率限制，三者不能混用。例如 QuantDash 文档写的是快照约 3 秒刷新一次，这是刷新频率。

**问：免费数据能直接用在商业产品里吗？**
答：不能默认可以。要读服务条款原文，确认使用范围和再分发限制；开源工具包的许可证只覆盖代码，不覆盖数据本身。

**问：QuantDash 免费能用什么？**
答：官网定价页写明，注册即获免费额度，包含 A 股实时行情和日 K 线；其他市场和数据类型需要对应方案，不同市场独立订阅。
